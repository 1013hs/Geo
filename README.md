# 🏔️ GeoSurveyToolbox 地质勘查工具箱

专业级安卓地质勘查GIS工具箱，支持高精度GNSS定位、轨迹记录、产状测量、赤平投影分析等功能。

## 技术栈
- Kotlin + Jetpack Compose
- MVVM + Repository + Hilt
- Room + SQLite
- GNSS Raw Measurements API
- Foreground Service
- Kalman Filter
